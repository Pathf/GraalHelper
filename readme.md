# Description

**GraalHelper** is a lightweight addon for World of Warcraft: The Burning Crusade Classic designed to help players quickly identify important combat effects during encounters.

The addon displays clear and responsive on-screen alerts for various buffs, debuffs, procs, and dangerous enemy abilities, allowing players to react faster in both PvE and PvP situations.

Whether tracking important dispellable effects, temporary combat states, or high-priority enemy mechanics, GraalHelper keeps essential information visible without overwhelming your interface.

Built with a focus on clarity, performance, and ease of use, the addon provides customizable visual warnings and flexible display settings while remaining lightweight and unobtrusive.

# Features

* Real-time combat effect alerts
* Visual tracking for buffs, debuffs, and special abilities
* Customizable warning sounds
* Adjustable UI scale and positioning
* Configurable display duration
* Optional effect name display
* Movable alert frames
* Lightweight and performance-friendly
* Simple and intuitive configuration menu
